### 30. Strong Number

Write a program to check whether a given number is a **Strong number** or not.

A number is called a Strong number if the sum of the factorials of its digits is equal to the number.

**Example:**

```text
Input: 145

1! + 4! + 5!
= 1 + 24 + 120
= 145

Output:
Strong Number
```
